# Contributing

Thank you for your interest in contributing! This project generates typeset Qur'an PDFs and a browsable HTML website using XeLaTeX and Python.

## Getting Started

1. Fork the repository and create a branch from `main`.
2. Install the prerequisites listed in [README.md](README.md#prerequisites).
3. Make your changes following the guidelines below.
4. Open a pull request with a clear description of what you've changed and why.

## Project Layout

| Directory | Purpose |
|-----------|---------|
| `src/` | Python generator scripts |
| `data/` | Source translation data (input files — do not modify) |
| `latex/` | LaTeX document templates and generated content files |
| `output/` | Build outputs (PDFs, plain-text files) — gitignored |
| `docs/` | Static HTML for GitHub Pages — regenerated by `src/gendocshtml.py` |
| `trans/` | Tanzil.net transliteration source with HTML tags (used by `gendocshtml.py`) |
| `archive/` | Legacy files kept for reference |

## Contribution Guidelines

### Python scripts (`src/`)
- Target **Python 3.6+** and follow [PEP 8](https://peps.python.org/pep-0008/).
- All scripts must be run from the **repository root**.
- Input paths use the `data/` prefix; output paths use `latex/` or `output/`.

### LaTeX templates (`latex/`)
- Document templates (`farooq.tex`, `suhail.tex`, etc.) are the main entry points compiled by XeLaTeX.
- Generated content files (`qum.tex`, `qup.tex`, …) are produced by `src/gentexforquran.py` — do not edit them by hand.

### HTML documentation (`docs/`)
- All files in `docs/` are auto-generated by `src/gendocshtml.py`. Edit the script, not the HTML directly.

### Translation data (`data/`)
- Raw source files — plain text, one line per ayah. Do not alter these unless correcting a genuine transcription error, and document the change clearly.
- Two sources use a **pipe-delimited** format (`sura|ayah|text`): `en.yusufali.txt` and `en.transliteration.txt` (comment lines starting with `#` are ignored).
- `translit_en.txt` uses a sequential `num|text` format aligned to global ayah order.
- `hindi-mokhtasar.json.zip` and `abridged-explanation-of-the-quran.json.zip` contain a single JSON file with a `"sura:ayah"` keyed object; these are read by `src/gentxtforquran.py` using Python's `zipfile` + `json` modules.

## Reporting Issues

Please open a GitHub issue with:
- A clear description of the problem or suggestion.
- Steps to reproduce (if a bug).
- The XeLaTeX / Python version you are using.

## Code of Conduct

Be respectful and constructive. This project deals with religious texts — please approach all discussions with sensitivity and care.
