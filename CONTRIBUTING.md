# Contributing

Thank you for your interest in contributing! This project generates typeset Qur'an PDFs
and a feature-rich static HTML website using XeLaTeX and Python.

## Getting Started

1. Fork the repository and create a branch from `cairo` (the default branch).
2. Install the prerequisites listed in [README.md](README.md#prerequisites).
3. Make your changes following the guidelines below.
4. Open a pull request against `cairo` with a clear description of what you changed and why.

## Project Layout

| Directory / File | Purpose |
|-----------------|---------|
| `src/` | Python generator scripts — run from the repository root |
| `data/` | Source translation data (input files — do not modify unless correcting a transcription error) |
| `latex/` | LaTeX document templates and generated content files |
| `output/` | Build outputs (PDFs and plain-text files) — gitignored |
| `docs/` | Static HTML for GitHub Pages — regenerated by `src/gendocshtml.py` |
| `trans/` | Tanzil.net transliteration with HTML tags used by `src/gendocshtml.py` |
| `archive/` | Legacy files kept for reference |

## Contribution Guidelines

### Python scripts (`src/`)
- Target **Python 3.6+** and follow [PEP 8](https://peps.python.org/pep-0008/).
- All scripts **must be run from the repository root** (not from inside `src/`).
- Input paths use the `data/` prefix; output paths use `latex/` or `output/`.
- `gendocshtml.py` must be run **after** `gentxtforquran.py` (it reads from `output/`).

### LaTeX templates (`latex/`)
- Document templates (`farooq.tex`, `suhail.tex`, etc.) are the main entry points
  compiled by XeLaTeX.
- Generated content files (`qum.tex`, `qup.tex`, `qus.tex`, `qut.tex`, `qupk.tex`) are
  produced by `src/gentexforquran.py` — do not edit them by hand.

### HTML documentation (`docs/`)
- All files in `docs/` are auto-generated by `src/gendocshtml.py`. Edit the generator
  script, not the HTML directly.
- `docs/search-data.js` is also auto-generated — do not edit by hand.

### Translation data (`data/`)
- Plain-text files have different formats:
  - **One line per ayah (sequential):** `ar.quran.txt`, `en.pickthall.txt`, `en.sahih.txt`,
    `hi.farooq.txt`, `hi.hindi.txt`, `en.transliteration.txt` (Tanzil.net).
  - **Pipe-delimited `sura|ayah|text`:** `en.yusufali.txt` (comment lines starting with `#`
    are ignored).
  - **Sequential `num|text`:** `translit_en.txt` (Quran Unicode Project; global ayah order).
  - **JSON ZIP:** `hindi-mokhtasar.json.zip` and `abridged-explanation-of-the-quran.json.zip`
    contain a single JSON file with `"sura:ayah"` string keys mapping to objects with a
    `"text"` field. These are read by `src/gentxtforquran.py` using Python's `zipfile` and
    `json` modules.
- Do not alter source files unless correcting a genuine transcription error, and document
  the change clearly in your PR description.

## Reporting Issues

Please open a GitHub issue with:
- A clear description of the problem or suggestion.
- Steps to reproduce (if a bug).
- The XeLaTeX / Python version you are using (for build issues).
- The browser and OS (for website issues).

## Code of Conduct

Be respectful and constructive. This project deals with religious texts — please approach
all discussions with sensitivity and care.
