# Glossary

Domain terms, project-specific jargon, and acronyms used throughout this repository and its documentation.

---

## A

**Abridged Explanation**
A concise English commentary on the Qur'an sourced from the JSON file `data/abridged-explanation-of-the-quran.json.zip`. Also referred to as "English Tafsir" in code. Displayed as a separate row on surah pages.

**Alafasy**
Mishary Rashid Alafasy, a Kuwaiti reciter of the Qur'an. The audio recitation files used in this project are his 128 kbps recording of all 6,236 ayahs.

**API**
Application Programming Interface. In this project, used colloquially to describe the Python script interfaces (`gentxtforquran.py`, `gentexforquran.py`, `gendocshtml.py`) — their inputs, outputs, and behaviour contracts.

**Ayah** (plural: **Ayat**)
A verse of the Qur'an. The Qur'an contains 6,236 ayahs in total across 114 surahs. Each ayah is identified by a `sura:ayah` reference (e.g., `2:255` = Surah Al-Baqarah, Ayah 255, famously known as Ayat al-Kursi).

---

## B

**Basmalah** (Arabic: بسم الله الرحمن الرحيم)
The opening phrase "In the name of Allah, the Most Gracious, the Most Merciful." Appears at the beginning of 113 out of 114 surahs (Surah 9, At-Tawbah, does not begin with it). In LaTeX, rendered by the `\basmalah` command from the `quran` package.

**BOM (Byte Order Mark)**
An invisible Unicode character (`U+FEFF`) sometimes prepended to UTF-8 files by Windows tools. Can cause `UnicodeDecodeError` when reading with Python's `open(..., encoding='utf-8')`. Handled by using `encoding='utf-8-sig'` or stripping it manually.

---

## C

**cairo**
The name of the default branch of this repository. All contributions should be made against `cairo`. The name is a reference to Cairo, Egypt — a centre of Islamic scholarship.

**Content Filter**
A collapsible UI widget on each surah page that allows users to toggle individual translation rows on or off. Implemented as HTML `<details>`/`<summary>` with JavaScript checkbox handlers.

**CTAN**
Comprehensive TeX Archive Network — the central repository for LaTeX packages. The `quran`, `polyglossia`, and related packages are distributed through CTAN and installed via `tlmgr`.

---

## D

**Dark Mode**
A visual theme that uses dark backgrounds and light text. Implemented on the website using CSS `prefers-color-scheme: dark` media query plus a JavaScript toggle button that saves the user's preference to `localStorage`.

**Devanagari**
The writing script used for Hindi, Sanskrit, and other South Asian languages. Hindi translation text in this project is in Devanagari script. Rendered in PDFs using the `{hindi}` LaTeX environment and Mangal/Lohit Devanagari fonts.

**docs/**
The directory containing the auto-generated static HTML website served by GitHub Pages. All files in `docs/` are generated by `src/gendocshtml.py` and should not be edited manually.

---

## F

**fawazahmed0/quran-api**
An open-source GitHub repository by Fawaz Ahmed that provides Qur'an translations via jsdelivr CDN. Many of the newer translations in `data/` (particularly the 27 added in the Feb 2026 update) were sourced from this API.

**Fontspec**
A LaTeX package (`fontspec`) that enables XeLaTeX to use system-installed OpenType and TrueType fonts. Required for rendering Arabic (Amiri, Scheherazade New) and Hindi (Mangal, Lohit Devanagari) fonts in PDFs.

---

## G

**gendocshtml.py**
The Python script in `src/` responsible for generating all HTML files in `docs/`. Takes data from `output/` (plain-text files) and `data/` (transliteration with HTML tags) as input.

**gentexforquran.py**
The Python script in `src/` responsible for generating intermediate LaTeX content files in `latex/`. Reads translation source data and produces `.tex` files interleaving Arabic Qur'an commands with translation text.

**gentxtforquran.py**
The Python script in `src/` responsible for generating formatted plain-text output files in `output/`. The primary data transformation script; produces 71 output files.

**GitHub Pages**
GitHub's static site hosting service. This project uses the `docs/` folder convention — GitHub Pages serves files from the `docs/` directory of the `cairo` branch at `https://druvx13.github.io/Quran-data/`.

**Gujarati**
An Indo-Aryan language spoken primarily in the state of Gujarat, India. One Gujarati translation is included: Rabila Al-Umry, sourced from `rabila-al-umry-simple.json.zip`.

---

## H

**Hafs**
The most widely transmitted narration (*riwaya*) of the Qur'an. The Arabic text in this project (`data/ar.quran.txt`, sourced from tanzil.net) follows the Hafs `an` Asim narration in Uthmani script. The `quran` LaTeX package also uses Hafs as its default.

**Hindi**
An Indo-Aryan language written in Devanagari script, spoken primarily in India. Several Hindi translations are included (Farooq Khan, Suhail, Al-Omari).

**Hugging Face Space**
A cloud service by Hugging Face for hosting machine learning models and demo applications. In this project, a Docker-based Space is used as a file server for the audio MP3 files. URL: `druvx13-quran-audio-alafasy.hf.space`.

---

## I

**Juz** (plural: **Ajza**)
One of the 30 equal portions into which the Qur'an is divided. Used for structuring recitation over a month (e.g., one juz per day during Ramadan). Referenced in `gendocshtml.py`'s metadata arrays.

---

## J

**JSON-in-ZIP**
The data format used by four source files in `data/` (Hindi Tafsir, English Explanation, Gujarati, Nepali). A standard ZIP archive containing a single `.json` file with `"sura:ayah"` keys mapping to objects.

---

## L

**LaTeX**
A typesetting system widely used for academic and scientific documents. This project uses **XeLaTeX** (a variant that supports Unicode and modern fonts) to produce bilingual PDF editions of the Qur'an.

---

## M

**Makefile / GNU Make**
The build system used in this project. The `Makefile` in the repository root defines five targets: `generate-tex`, `all`, `generate-txt`, `generate-docs`, and `clean`.

**Meccan** / **Medinan**
Classification of Qur'anic surahs based on whether they were revealed before (*Meccan*) or after (*Medinan*) the Prophet Muhammad's migration (Hijra) from Mecca to Medina. Most shorter surahs are Meccan; longer ones dealing with law and community are Medinan. Displayed on surah page headers in the website. Abbreviated `M` (Meccan) and `D` (Medinan/Madani) in `SURAH_REV`.

**Mushaf**
The physical or canonical written copy of the Qur'an. The "Mushaf order" refers to the standard ordering of surahs as they appear in the printed Qur'an (Surah 1 through 114), as opposed to the chronological order of revelation.

---

## N

**Nepali**
The official language of Nepal. One Nepali translation is included: Ahl-al-Hadith Central Society of Nepal, sourced from `ahl-al-hadith-central-society-of-nepal-simple.json.zip`.

---

## O

**output/**
The directory containing generated build artefacts. Plain-text files are tracked in git; PDF files are gitignored. All files in `output/` are generated by `gentxtforquran.py` or compiled by XeLaTeX.

---

## P

**Pickthall**
Mohammed Marmaduke Pickthall (1875–1936), a British author who produced one of the earliest widely-read English translations of the Qur'an (1930). His translation is in the public domain.

**Pipe-delimited**
A text format where fields are separated by the `|` character. Used by Tanzil.net downloads: `sura|ayah|text`. Parsed in Python with `line.split('|', 2)[2]`.

**Polyglossia**
A LaTeX package for multilingual typesetting, used as a replacement for `babel` with XeLaTeX. Handles bidirectional text, font selection, and language-specific hyphenation rules.

---

## Q

**quran (LaTeX package)**
A LaTeX package that provides the `\quranayah[sura][ayah]` command to typeset any ayah from the Qur'an in the Hafs narration. Used in all five PDF templates.

**quran.sty**
The custom LaTeX style file in `latex/`. Configures fonts, page layout, language environments, and re-exports the `quran` package for use in template files.

**quranenc.com**
An online Qur'an translation resource. Source of the English Rowwad Translation Center (`en.rwwad.txt`) and Hindi Al-Omari (`hi.omari.txt`) translations.

**quran.com**
An online Qur'an resource providing translations via API. Source of translations including Mufti Taqi Usmani (`en.usmani.txt`), M.A.S. Abdel Haleem (`en.abdelhaleem.txt`), and several Urdu translations.

---

## R

**Revelation Order**
The chronological order in which Qur'anic surahs were revealed to the Prophet Muhammad, as distinct from the Mushaf order in which they are arranged in the canonical text. Stored in `SURAH_REV` in `gendocshtml.py` and displayed on surah page headers.

**Roman Urdu** / **Roman Hindi** / **Roman Gujarati**
Transcriptions of Urdu, Hindi, and Gujarati texts using the Latin (Roman) alphabet instead of the native scripts (Nastaliq/Naskh, Devanagari, Gujarati). These are phonetic representations for readers not familiar with the native scripts.

**Rukū** (plural: **Rukūʿāt**)
A section of the Qur'an that ends at a point suitable for bowing in prayer. Used as a recitation unit in some traditions.

---

## S

**Sajdah** (plural: **Sajdāt**)
Prostration. There are 15 places in the Qur'an where it is recommended or obligatory to perform a prostration upon recitation. Referenced in metadata arrays in `gendocshtml.py`.

**search-data.js**
A generated JavaScript file in `docs/` that contains a pre-built search index for the full-text search functionality. Updated every time `gendocshtml.py` is run.

**sura** / **surah** (plural: **suwar**)
A chapter of the Qur'an. The Qur'an has exactly 114 surahs. In code, surahs are numbered 1–114 (1-indexed).

**surasize**
A Python list (length 114) defined in the generator scripts. Each element is the number of ayahs in the corresponding surah. The sum is always 6,236.

**suraname**
A Python list (length 114) of English surah names in the format `"Arabic-Name (English-Translation)"`.

---

## T

**Tafsir** (plural: **Tafasir**)
Qur'anic exegesis — scholarly commentary and explanation of the Qur'an's meaning. In this project, the Hindi Tafsir from Al-Mokhtasar is included.

**tanzil.net**
A comprehensive Qur'anic resource providing Arabic text and translations in standardized formats. Source of many translations in this project (Pickthall, Yusuf Ali, Sahih, transliteration, and others).

**tlmgr**
TeX Live Manager — the command-line tool for installing and updating LaTeX packages in a TeX Live installation. Used to install `quran`, `polyglossia`, and other required packages.

---

## U

**ULI (Unconditional Liberty Instrument)**
The custom open-source license used for this project's scripts and configuration files (Version 1.0). A public-domain-equivalent license granting unrestricted use, modification, and distribution rights.

**Urdu**
An Indo-Aryan language written in a Perso-Arabic script (Nastaliq style), spoken primarily in Pakistan and parts of India. Multiple Urdu translations are included (Jalandhry, Junagarhi, Maududi, and others).

**Uthmani Script**
The canonical Arabic script for the Qur'an, established during the caliphate of Uthman ibn Affan. This is the script used in `data/ar.quran.txt` and rendered by the `quran` LaTeX package.

---

## X

**XeLaTeX**
A variant of the LaTeX typesetting engine with native Unicode support and the ability to use any system-installed OpenType/TrueType font. Required for this project's PDF generation because of Arabic, Hindi, and other non-Latin scripts.

---

## Y

**Yusuf Ali**
Abdullah Yusuf Ali (1872–1953), an Indian-British author who produced a well-known English translation of the Qur'an with commentary (1934). His translation is in the public domain. Data file: `data/en.yusufali.txt` (pipe-delimited format).
